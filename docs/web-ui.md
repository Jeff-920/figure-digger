# DIG 网页使用指南

## 启动

先激活安装本项目依赖的 Python 环境，再进入项目目录运行：

```bash
python -m pip install -r requirements.txt
python app.py
```

浏览器打开 [http://127.0.0.1:8501](http://127.0.0.1:8501)，使用期间保持终端运行。默认监听 `127.0.0.1:8501`，只在本机可访问。

端口被占用时：

```bash
python app.py --port 8502
```

也可以设置环境变量 `DIG_PORT` 或 `DIG_HOST`。安装和启动应使用同一个 Python 环境；也可以将 `python` 换成该环境解释器的完整路径。

网页依赖固定版本的 Flask 与 Waitress。未安装 Waitress（例如只安装了部分依赖）时会退回 Flask 内置服务器，功能仍可用；安装 `requirements-web.txt` 即启用 Waitress。

## 页面与流程

网页首页是“任务结果”，可以搜索、筛选和重新打开历史任务。点击“新建提取”进入表单：

1. 上传一篇或多篇 PDF，可选上传 `.txt`、`.dat` 或 `.csv` 模板。
2. 填写图号或目标描述；留空会处理检测到的全部数据图。按图号、内容或工况查找均由视觉模型完成。
3. 选择“自动提取”或“仅分析，稍后确认坐标”。所有提取任务都使用视觉模型；仅分析一次处理一篇，模板导出需要自动提取。
4. 展开“更多设置”可填写页码、DPI、批量并行数和相应开关。页码使用 PDF 实际页序，从 1 开始，格式如 `3,5,7`；选择文件后页面会读取页数，提交时服务器再次校验。
5. 点击“开始处理 PDF”。提交成功后进入任务详情页，任务在后台运行，可以离开页面。

任务按提交顺序串行执行；每个批量任务内部仍可通过“批量并行数”并行处理。关闭或刷新浏览器不会中断后台任务。服务重启时，仍在排队或运行的任务会被标记为“已中断”，不会自动重跑或续跑。

任务列表中的任务 ID 可展开，按文献显示每篇的状态、结果数量、曲线数和错误原因。每篇文献右侧的眼睛按钮会直接打开该文献的核对视图，图像、CSV、模板和报告都只显示这篇文献的文件。批量任务中一篇失败不会掩盖其他文献的结果；全部文献失败时任务状态为“处理失败”，部分失败则为“部分失败”。

## 状态与详情

列表和详情页区分以下结果，不只根据退出码显示成功：

| 状态 | 含义 |
| --- | --- |
| 排队中 / 运行中 | 后台任务尚未结束。详情页展示状态和日志尾部。 |
| 提取完成 · 待核对 | 已生成 CSV 或模板，但尚未人工核对。 |
| 分析完成 · 待确认坐标 | 仅完成分析，需要先确认坐标轴范围。 |
| 未提取到数据 | 命令正常结束，但没有 CSV 或模板。 |
| 部分失败 | 批量任务中部分论文失败；总体命令可能仍以 0 退出。 |
| 处理失败 | 处理程序异常退出，查看日志与报告。 |
| 已中断 | 服务重启时任务未完成；未自动重试。 |

运行期间，详情页每 1.5 秒查询一次状态和日志尾部；任务结束、失败或中断后停止查询，并自动刷新一次详情。选择预览文件或查看核对图时不会持续整页刷新。

详情页保留六个结果标签：

- **文献核对**：按文献列出状态、页数、CSV/核对图/报告数量、曲线数和错误原因。
- **图像核对**：先点选起点（自动吸附最近点），再拖动“采样间隔”确定这条曲线的点集；只有采样后的点才进入编辑。向左更稀疏，向右更密集。当前曲线编辑后分辨率锁定。左侧编辑栏提供：
  - 移动：拖动当前曲线的采样点，折线跟随。
  - 擦除：在当前曲线上按住拖动，删除点并断开折线；断开后不足两个点的片段会移除。
  - 补充：先放新点，再点左、右两个锚点；相邻点之间插入，或把断裂段的末端与起点接回。若接的是曲线端点，放好新点后直接双击该端点即可追加，不需要第二个锚点。
  - 新建：沿缺失曲线依次点击，完成后追加一条新曲线。
  - 撤销/还原；保存会把修改过的曲线写回各自 CSV，新建曲线会追加 CSV。断开的线段用空行分隔；一张图的多条曲线按当前选中的曲线分别保存。
  - 右侧“曲线成图”在编辑后确认绘制，使用当前页面中的最终点集；X/Y 轴标签可编辑，默认读取面板轴标题（没有元数据时用 Time (ms) / Liquid Penetration (mm)）。成图的线条、标记和图例颜色与左侧对应曲线一致。
  - 每个轴可填单位换算“× 倍率 + 偏移”，例如 µs→ms 填 `0.001`。换算只影响右侧成图和保存的 CSV，左侧原图和像素编辑坐标保持不变。保存时会把换算后的值写回 CSV，并同步更新该面板的轴范围与轴标签，刷新后仍按换算单位显示。
  - 鼠标在左侧图像上移动时显示跟随鼠标的 3× 圆形放大镜，中心十字，起点模式高亮最近候选点；擦除时显示笔刷范围，补充时显示新点与锚点。
  - 曲线图例是按钮：点击图例即确认当前曲线，活动项带对勾。多条曲线重叠时，起点点击优先落到当前曲线；要切换曲线直接点图例，移动/擦除/补充始终只作用于当前曲线。
- **曲线数据**：CSV 最多预览前 200 行，下载包含全部数据。
- **模板文件**：转义后的文本预览，可下载原始文件。
- **报告**：转义后的文本预览，可下载报告。
- **日志与配置**：实际执行参数（不含 API Key）、坐标配置下载和运行日志。

“下载全部结果”在点击时生成 ZIP 并下载，不会在列表加载或每次轮询时打包。

## 仅分析与坐标确认

坐标轴较模糊或数值要求很严时，可先选“仅分析”。确认坐标范围仍在命令行完成：

```bash
python run.py confirm <配置文件路径> --id <面板ID> --x 0,5 --y 0,70
python run.py extract <配置文件路径>
```

上面的范围仅为命令示例，请按原图刻度填写。配置文件可从任务详情的“日志与配置”下载。网页与命令行调用同一套提取算法。

## API Key

视觉模型需要 DeepSeek API Key。可以在“密钥设置”中明确保存，或在新建页填写并勾选“记住 API Key（保存在本机）”；后者会在提交任务时写入项目根目录的 `deepseek_key.txt`。页面只显示是否可用，不回显已保存的密钥。

取消勾选“记住”时，新输入只用于当前任务，之前保存的密钥文件仍保留。清除操作只删除本机密钥文件；环境变量 `DEEPSEEK_API_KEY` 不受影响。环境变量和 `secrets.json` 也可提供密钥。

密钥不会进入 URL、任务元数据、实际命令数组、日志或结果压缩包。子进程通过环境变量 `DEEPSEEK_API_KEY` 接收当前任务的密钥。

## 文件位置与兼容性

- 上传文件、`ui-run.json`、`ui-run.log` 与结果保存在项目的 `.ui_workspace/<任务ID>/`，关闭浏览器不会删除。
- 结果位于 `output/`：CSV 在 `csv/`，核对图在 `verify/`，报告、配置和模板也在该目录下。
- 兼容已有 `.ui_workspace` 和旧版 `ui-run.json`；旧记录缺少新字段时显示“未记录”或从已有参数推导，不批量改写旧文件。
- `.vlm_cache/` 保存模型响应缓存，`.vlm_log.jsonl` 记录调用明细；这些本机文件默认已加入 Git 忽略规则。
- 静态资源 Bootstrap 5.3.8 与 Font Awesome Free 6.7.2 随项目提供，正常使用不依赖 CDN。

## 常见问题

- **端口被占用**：使用 `python app.py --port 8502`，访问对应地址。
- **未安装 Waitress**：启动时会提示并改用 Flask 内置服务器；安装 `requirements-web.txt` 后重启即可。
- **提示页码超出**：页码指 PDF 实际页序，不是论文印刷页码或图号；确认文件页数后调整。
- **没有 CSV 或核对图**：查看报告与日志，确认是否选中目标数据图、是否仍处于仅分析阶段，或自动轴范围是否未确认。
- **任务显示已中断**：服务在任务运行时重启；当前不支持断点续跑，请重新提交。
- **视觉模型失败**：检查密钥、接口地址、网络和接口限流；矢量图仍可直接从 PDF 路径提取。
- **结果是否可信**：自动结果必须结合核对图复查，重点检查坐标数量级、系列完整性和曲线贴合情况。网页不会把未核对结果标为“已核对”。

本轮不提供任务删除、账户系统、数据矩阵或网页坐标编辑器。网页是本地单机服务，默认只监听回环地址，没有公网访问保护。
