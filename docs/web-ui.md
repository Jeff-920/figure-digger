# DIG 网页使用指南

## 启动

先激活安装本项目依赖的 Python 环境，再进入项目目录运行：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501 --browser.gatherUsageStats false
```

浏览器打开 [http://127.0.0.1:8501](http://127.0.0.1:8501)，使用期间保持终端运行。安装和启动应使用同一个 Python 环境；也可以将 `python` 换成该环境解释器的完整路径。端口被占用时，将 `--server.port` 改为 8502，并访问对应地址。

仅使用视觉模型、不需要 OCR 时，可将安装命令换为：

```bash
python -m pip install -r requirements-core.txt -r requirements-web.txt
```

## 提取与核对

1. 在“开始提取”上传一篇或多篇 PDF，可选上传 `.txt`、`.dat` 或 `.csv` 格式模板。
2. 填写图号或目标描述；留空会处理检测到的全部数据图。按内容或工况查找需要视觉模型，本地 OCR 仅支持纯图号约束。
3. 选择“自动提取”或“仅分析，稍后确认坐标”，并选择视觉模型或本地 OCR。仅分析一次处理一篇；模板导出需要视觉模型与自动提取。
4. 在“更多设置”按需填写页码、DPI 和批量并行数。页码使用 PDF 实际页序，从 1 开始，格式如 `3,5,7`。视觉模型默认关闭 OCR，可开启交叉核对。
5. 开始处理。完成后先查看“图像核对”，检查坐标范围、系列是否齐全及追踪是否贴合原图，再下载 CSV、模板或全部结果。

“图像核对”仅展示 `verify/` 中的结果叠加图。“报告”和“日志与配置”可查看处理失败、选图或坐标识别问题。“任务结果”可重新打开历史任务。

默认接受未确认的自动轴范围。数值要求严格时，可关闭对应开关，或先选“仅分析”，下载配置并确认后提取：

```bash
python run.py confirm <配置文件路径> --id <面板ID> --x 0,5 --y 0,70
python run.py extract <配置文件路径>
```

上面的范围仅为命令示例，请按原图刻度填写。网页与命令行调用同一套提取算法。

## API Key

网页默认勾选“记住 API Key（保存在本机）”。首次填写后，密钥以明文保存在项目根目录的 `deepseek_key.txt`；后续任务、刷新网页或重启服务均可复用，输入框留空即可。点击“清除已保存的 API Key”可删除该文件并清空输入框。

取消记住后，新输入仅在当前会话和任务中使用，之前保存的文件仍保留。环境变量 `DEEPSEEK_API_KEY` 和 `secrets.json` 也可提供密钥；环境变量优先于密钥文件。网页保存的密钥不会写入任务配置、任务日志和结果压缩包，密钥文件已加入 Git 忽略规则。

## 文件位置与常见问题

- 上传文件、日志和提取结果保存在项目的 `.ui_workspace/<任务ID>/`，关闭浏览器不会删除。
- `.vlm_cache/` 保存模型响应缓存，`.vlm_log.jsonl` 记录调用明细；这些本地文件均不提交到 Git。
- 提示缺少模块或不支持某个网页参数：确认当前 Python 环境正确，并重新安装对应依赖；网页要求 `streamlit>=1.50`。
- 没有 CSV 或核对图：查看报告与日志，确认是否选中了目标数据图、坐标是否已确认，以及是否仍处于仅分析阶段。
- 任务耗时较长：已知页码时缩小页码范围，填写目标图号或描述，按需提高批量并行数。并行数受本机内存和接口限流约束。
